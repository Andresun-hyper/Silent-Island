# 孤岛 App PRD

## 产品定位

孤岛是一个以水彩小世界为载体的私密心情手记。用户写下一句当下的心事，选择天气与一种造景，让字迹化成鸟、花或灯火，留在岛上。

产品的核心不是奖励、打卡或社交，而是一个轻量闭环：抵达风景、表达、安放、再回来看看。不提供心理诊断、治疗承诺或 AI 情绪评判。

## 核心体验

- 打开就进入可交互风景，不增加营销首页或强制注册。
- 一条连续的立体小路串起旷野、池畔、暮灯、竹径。池畔的长木桥真正跨水，房屋位于平整地基上，屋前缓降、屋后为起伏疏林。
- 按用户新增的 3D 需求，用沿路推进和轻微转向取代静态镜头；保留电线拖拽、张力抑制抖动与回弹的交互语义。
- 写下 1 至 280 个字符，选择平静、晴朗、阴天或有点累，再选择鸟、花或灯。
- 保存成功后文字成为造景；点选它或打开手记即可回看、修改、移到纸篓与恢复。
- 可以暂停摇曳、导出当下明信片，或导出 / 导入完整手记备份。
- 声音默认关闭，主动开启后按位置混合风、水、竹磬和五声音阶合成拨弦；不是实录古琴或 AI 模型生成音乐。

## 数据与边界

- 本版是 local-first 静态 App；手记与草稿存在当前浏览器的 localStorage，不上传，无账户、云同步或加密承诺。
- JSON 备份包含版本、正文、天气、造景、地点、创建 / 更新时间和可恢复的删除标记。
- 导入先校验再合并，按照更新时间保留较新的记录；不清空现有内容，不允许旧备份复活已删除的记录。
- 读取失败时保留原始数据，可导出原始备份；写入失败时保留输入，不显示保存成功。
- 纸篓只做可恢复删除，不设置自动清空或永久删除。
- 同时绘制最多 12 条手记造景，剩余内容仍保存在手记列表；回看更早内容时把选中造景放回场景。
- 备份文件最多 8 MiB、5,000 条记录；限制用于防止异常文件阻塞页面。
- 浏览器数据清理、切换域名或设备不会自动迁移手记，需用导出 / 导入。

## 视觉约束

- 延续灰纸、暖灰墨线、疏淡晕染和细微动态；3D 实现不宣称逐参数复刻旧 Canvas。旧渲染器保留在源代码中。
- 草地以灰棕墨色和细线为主，保留小路周围的留白，不增加全屏暗角和大面积绿色晕染。
- 生成草丛贴图实例化，细草线在 GPU 上摇曳，建筑与枝干合批。墨韵 Shader 的强度可调。
- 四个地点共用连续地形，不拆成装饰卡片；操作界面用手写标题与克制的图标工具栏。
- 桌面使用侧边手记面板，手机使用全屏手记面板。两端独立取景并保持真实透视比例；标题、场景、底部控制分区布局。
- 尊重系统减少动态设置；提供风景暂停、键盘操作、原生模态焦点约束与 Escape 关闭。

## 验收标准

- 四个地点可沿路往返；暂停环境动态时仍能移动，不陷入空白过渡。
- 空内容不可保存；草稿关闭再打开仍在；保存后刷新可回看。
- 搜索、天气筛选、修改、纸篓恢复形成完整闭环。
- 备份往返不会制造重复条目；非法备份不会改动已有内容。
- 生成的 PNG 明信片包含当前风景、一句话和地点日期。
- 桌面、窄手机、横屏窗口都无横向溢出，Canvas 非空、对象未变形，面板内容可滚动。
- lint、TypeScript、数据单元测试与静态生产构建通过；实际界面与测试截图另记于开发验收。
