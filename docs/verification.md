## 已知验证限制

- PNG 明信片与 JSON 备份生成后会出现可再次点击的下载链接。
- 内置浏览器的下载等待接口未返回下载文件；生成流程已触发，但最终下载落盘没有确认。需要在普通浏览器补测，不把此项报告为已完成的端到端下载验证。
- localStorage 没有云同步或加密。换设备、换域名、清理浏览器数据前，需要自行备份。
